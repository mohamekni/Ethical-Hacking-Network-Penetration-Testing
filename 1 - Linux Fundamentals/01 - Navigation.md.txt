01 — Linux Navigation Commands

1. pwd — Print Working Directory

>> pwd
Display the current working directory.

---

2. cd — Change Directory

>> cd /home/kali
>> cd ..
>> cd ../..
>> cd ~
>> cd -
>> cd /

cd /home/kali : Go to a specific directory
cd .. : Go to the parent directory
cd ../.. : Go up two directory levels
cd ~ : Go to the current user's home directory
cd - : Return to the previous working directory
cd / : Go to the filesystem root

---

3. Absolute and Relative Paths
Absolute path: starts from the root directory /.
>> cd /home/kali/Documents

Relative path: starts from the current working directory.
>> cd Documents
>> cd ../Downloads

---

4. tree — Display Directory Structure

>> tree
>> tree -L 2
>> tree -a
>> tree -d

-L 2 : limit the display to two directory levels.
-a : include hidden files.
-d : display directories only.

Install it if necessary:
sudo apt update
sudo apt install tree

---

5. clear — Clear the Terminal
>> clear
Keyboard shortcut:
ctrl + L
